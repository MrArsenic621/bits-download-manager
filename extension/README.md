# Bits Download Manager — Browser Extension Companion

The companion browser extension allows you to download any file, image, or link directly with **Bits Download Manager** via right-click context menu or automatic download interception.

---

## Installation (Chrome, Edge, Brave, Opera)

1. Open your browser's extension manager:
   - Chrome: `chrome://extensions`
   - Edge: `edge://extensions`
   - Brave: `brave://extensions`
2. Enable **Developer mode** (toggle in the top-right corner).
3. Click **Load unpacked**.
4. Select the `extension/` folder in this repository.

---

## Features

- **Right-Click Context Menu**: Right-click any link, video, audio, or image and choose *"Download with Bits Download Manager"*.
- **Automatic Interception**: Optional toggle to catch all browser downloads automatically and route them to Bits for maximum download acceleration.
- **Cookies & Session Forwarding**: Automatically forwards session cookies and Referer headers so authenticated downloads work seamlessly.
- **Quick Download Popup**: Click the extension icon to paste any URL or check connection status to Bits desktop app.
